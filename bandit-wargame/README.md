# OverTheWire: Bandit Wargame Walkthrough

This repo contains my personal solutions and notes as I work through the [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) wargame. The Bandit game is designed to teach the basics of the Linux command line and foundational hacking skills. I'm tackling one level per day to build up fluency with shell commands, permissions, and basic cybersecurity techniques.

---

## 🎯 Goal

To complete all 34 levels of the Bandit wargame and reinforce my understanding of:

- Linux command-line tools (`ls`, `cat`, `find`, `grep`, etc.)
- File permissions and ownership
- SSH and remote connections
- Input/output redirection and piping
- Basic scripting and problem-solving
- Real-world hacker mindset and debugging

---

## 🗂️ Project Structure

Each level has its own folder with notes and (if needed) scripts

Each `levelXX` folder includes:

- Explanation of the level along with my solutions
- Any helper scripts or notes I used while solving
