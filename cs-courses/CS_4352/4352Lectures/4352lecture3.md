## **Visual Design Principles in HCI**

---

This lecture introduces visual design concepts for web and mobile interfaces as part of Module 3 in an HCI course.

### Core HCI Concepts

- Human (user) interacts with Computer (machine) through an Interface
- Good design focuses on making this interaction intuitive and effective

### Visual Design Fundamentals

- Goals: Convey structure and draw users in
- Examples: New York Times (clear hierarchy) vs. Google (minimalism)
- Basic improvements with white space, size contrast, and alignment enhance readability

### Typography

- Serif vs. Sans Serif fonts: traditionally serif for print body text, sans serif for headings
- Online: sans serif often preferred for web content
- User expectations significantly impact text readability
- Text positioning affects perception (demonstrated through visual illusions)

### Layout

- Grid systems organize content and navigation
- New York Times uses 5-column grid for content, 1 column for navigation
- Context view: image on top, article text below (no grid)
- Effective forms align labels and input fields consistently (Amazon example)

### Alignment

- Left alignment: fastest for skimming in English
- Centered alignment: slower to read, good for headers
- Right alignment: useful for specific contexts like forms and invitations
- Scale (font size variation) indicates hierarchy of importance

### Color Usage

- Start with black and white/grayscale design first
- Add color conservatively after other elements work
- Guidelines:
  - Limit number and amount of colors
  - Support the task at hand
  - Consider color-blind users
  - Maintain consistency in color coding
  - Be aware of cultural expectations about color meanings
  - Avoid problematic color combinations

## **User Interface Design: Affordances and Web Design Principles**

---

This lecture from Module 3 explores affordances in design and best practices for web interfaces.

### Understanding Affordances

- Affordances are perceived and actual properties of objects that suggest how they should be used
- Examples: chairs for support, handles on teapots for holding, buttons for pushing
- Effective design allows users to understand functionality without instructions
- Design fails when perceived affordances are inaccurate (e.g., buttons that look pushable but aren't)
- Simple objects shouldn't require labels or instructions; if they do, the design has failed

### Digital Affordances and Conventions

- Digital interfaces have established conventions users expect (e.g., "Add to cart" buttons)
- Deviating from standards causes confusion (non-QWERTY keyboards, scroll bars not on right)
- Human culture changes slowly, so observing users in natural environments is essential
- Signs of good design: users navigate confidently without frequent backtracking

### Six Design Principles

- Visibility: Make functions clearly visible
- Feedback: Provide clear information about what's happening
- Consistency: Follow existing standards and conventions
- Non-destructive: Allow users to undo actions
- Discoverability: Enable users to find all functionality
- Reliability: Ensure consistent, predictable behavior

### GUI vs. Command Line

- GUI advantages: visibility, good feedback, consistency, non-destructive, discoverable
- Command line limitations: requires knowledge of commands, minimal feedback, error-prone
- Command line benefits: can express things abstractly, potentially more efficient for complex tasks

### Web Design Best Practices

- Use specific icons rather than generic ones
- Add redundant coding (e.g., text with icons) for clarity
- Use longer, descriptive links instead of single words
- Limit titles to 7-8 words for readability
- Prioritize top-left content (highest user attention in left-to-right languages)
- Place best content at the top to encourage scrolling
- Design for scanning, not reading (users don't read websites thoroughly)
- Use scannable formats: headings, bullet lists, short paragraphs

### User Behavior Online

- Users typically switch between multiple tabs and devices
- Unlike reading books, web browsing involves different contexts and styles
- Design must accommodate scanning behavior and shorter attention spans

## **Analyzing Ronaldo's Mental Edge: Eye-Tracking Study Reveals Soccer Genius**

---

This transcript documents a scientific study examining how Cristiano Ronaldo's mental abilities and spatial awareness contribute to his exceptional soccer performance. Using state-of-the-art eye-tracking technology, researchers analyze the differences between Ronaldo's visual processing and that of a typical player.

### Test Setup and Methodology

Sports psychologist Zoe Wimshurst and equipment specialist John Ward conducted the test using eye-tracking technology that captures where Ronaldo looks during play. The researchers noted that 80-90% of the information athletes process comes through their eyes. During the test, Ronaldo attempted to keep the ball away from a player named Andy while both wore eye-tracking equipment.

### Ronaldo's Visual Processing Abilities

The eye-tracking data revealed that unlike typical players who focus primarily on the ball, Ronaldo consistently scans his environment. He divides his attention between the ball, his opponent's body positioning (particularly hips and feet), and spaces beyond the defender. This comprehensive visual awareness allows Ronaldo to anticipate movements rather than merely react to them.

### Performance Comparison

When analyzed in slow motion (one-third actual speed), researchers found that Ronaldo executed 13 different moves in just 8 seconds, including step-overs and spins. In contrast, Andy primarily focused on tracking the ball, which limited him to reactive movements rather than anticipatory ones. This fundamental difference in visual processing helps explain why Ronaldo consistently maintains an advantage over opponents.
