## **Lecture on Mental Models**

---

Mental models are one of the most important concepts in human-computer interaction, representing how users think something works. These abstract representations form based on past experiences, training, and instruction, allowing users to make predictions about unfamiliar systems.

### Understanding Mental Models

Mental models represent the cognitive processing that happens in human brains, including perceiving, thinking, remembering, and problem-solving. Different users construct different mental models for the same scenarios, as illustrated by the obesity example where health professionals and patients have contrasting beliefs about the same condition.

Users form mental models about everything they interact with daily, from refrigerators and car transmissions to interactions with animals and other humans. As Albert Einstein noted, "to break a mental model is harder than splitting the atom," highlighting the concept of mental model inertia.

### User vs. Designer Mental Models

A critical distinction exists between:

- Designer's mental model: the conceptual model of the system being built
- User's mental model: how users think the system works

Don Norman's refrigerator example demonstrates this mismatch perfectly. Norman expected both dials to directly control temperature, but one actually controlled overall temperature while the other distributed it. When mental models don't align, it leads to frustration, slow performance, and errors.

### Types of Errors

When users interact with systems, two types of errors can occur:

- Slips: Users have the correct mental model but make execution errors
- Mistakes: Users perform intended actions but have the wrong mental model

Slips can be prevented through better visual and tactile design elements. Mistakes are harder to rectify as they require aligning the user's mental model with the system's actual functionality.

### Bridging the Gap

To close the gap between designer and user mental models:

- Reduce the "gulf of execution" (distance between user goals and means to achieve them)
- Minimize the "gulf of evaluation" (effort required to determine system state)
- Test products with real users and gather feedback
- Implement good design principles like direct manipulation

### Design Principles and Examples

The 2018 Hawaii missile alert false alarm illustrates the dangers of poor design. An employee selected the wrong option during a test, causing widespread panic. Don Norman blamed this on "incompetent design," not user error.

Good design practices include:

- Preventing errors by requiring confirmation
- Eliminating irreversible actions
- Providing mechanisms to undo actions
- Creating interfaces that disclose how they're used
- Translating users' cognitive capabilities into intuitive interfaces

## **Human Information Processing Video**

---

This presentation explains how human memory functions through the Atkinson and Shiffrin information processing model, describing how information moves through three distinct memory systems.

### The Information Processing Model

The Atkinson and Shiffrin model views humans as information processors similar to computers. Information passes through three main memory sites: sensory memory, short-term/working memory, and long-term memory.

### Sensory Memory

- First stage of memory processing where environmental information is temporarily registered
- Two main types: Iconic Memory (visual) and Echoic Memory (auditory)
- Visual memories are vivid but last less than half a second
- Auditory memories last 3-4 seconds
- Only information we pay attention to moves to short-term memory

### Working Memory (Short-term Memory)

- Previously called short-term memory, now commonly referred to as working memory
- Holds approximately seven pieces of information at once
- According to Bradley and Hitch's theory, includes several components:
  - Central executive: coordinates and controls all cognitive processes
  - Visuospatial sketchpad: processes visual information
  - Phonological loop: processes verbal information
  - Episodic buffer: temporarily stores and organizes information before transfer to long-term memory
- Information can be lost through interference, decay, or retrieval failure

### Long-term Memory

- Storage system for all knowledge and memories
- Contains both inactive (unconscious) memories and activated memories that can be transferred to working memory
- Information can be lost through decay
- Requires rehearsal or deep processing to retain information

### Memory Retention

- Information needs to be rehearsed or deeply processed to maintain it in short-term memory
- Same techniques help transfer information to long-term memory for permanent storage

## **Product Review Homework Video**

---

This instructional session explains the expectations for writing product reviews as part of homework assignment #2.

### Good vs. Bad Reviews

- The quality of a review is NOT determined by the star rating (5-star vs 1-star)
- A "bad" review lacks depth and provides minimal details (e.g., "Great, it's worth a buy")
- A "good" review provides in-depth information regardless of rating:
  - Detailed explanations of features
  - Specific reasons why things work or don't work
  - Comprehensive analysis of the product

### Examples Shown

- An Amazon treadmill product page was used as an example
- Demonstrated a 5-star review that was considered "bad" due to lack of details
- Showed a review considered "good" because it provided extensive information
