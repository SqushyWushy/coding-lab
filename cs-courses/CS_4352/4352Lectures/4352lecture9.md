## **Web Accessibility Principles and Guidelines**

---

### What is Accessibility?

- Ensuring equivalent user experience for people with disabilities
- Allowing everyone to perceive, understand, navigate, and interact with web content
- Over 1 billion people worldwide (about 20% of the population) have some form of disability
- Universal design aims to create solutions that work for as many people as possible

### WCAG Principles

The Web Content Accessibility Guidelines are based on four core principles:

1. **Perceivable**
   - Information must be presentable in ways users can perceive
   - Alternative text for images for screen reader users
   - Captions and transcripts for audio/video content for deaf users
   - Don't rely solely on color to convey information (4.5% of the population is colorblind)
   - Use multiple visual cues like texture and numbers alongside color
2. **Operable**
   - User interface components and navigation must be operable by everyone
   - All functionality should be available using a keyboard
   - Implement tabindex and access keys for keyboard navigation
3. **Understandable**
   - Content must be readable and understandable
   - Web pages should operate in predictable ways
   - Help users avoid and correct mistakes
4. **Robust**
   - Content must be interpretable by various user agents and assistive technologies
   - Use proper HTML structure with start/end tags and unique IDs
   - Implement appropriate nesting of elements

### Implementation Tips

- Use proper heading structure (h1, h2 tags)
- For tables, use TH tags for header cells to help screen readers
- Label form elements with the label tag
- Provide clear error messages and recovery options
- Validate HTML code to ensure compatibility with assistive technologies

### Resources Mentioned

- WAVE accessibility checker by WebAIM
- Multiple accessibility checking tools for readability and colorblindness
- HTML validators
