### What Are Prototypes?

Prototypes are simulations of final products created using visuals. They serve to test if the product flow is smooth and consistent with user needs, and to evaluate the feasibility and usability of designs before writing code, which is typically more expensive. Prototypes are not meant to be final products.

### Types of Prototypes

**Paper Prototypes (Low-Fidelity)**

- Created after storyboarding to visualize interface design
- Uses paper and markers for quick sketching
- Advantages:
  - Much faster than programming
  - Provides early feedback
  - Easy to modify
  - Helps focus on big picture
  - Accessible to non-programmers
  - Cost-effective
- Tips: Use reusable components, photocopying, and printable sketching templates

**High-Fidelity Prototypes**

- Digital mock-ups with high visual and functional fidelity
- Transform paper prototype ideas into realistic working prototypes
- Created using prototyping software without coding:
  - Figma ([figma.com](http://figma.com))
  - Marvel app ([marvelapp.com](http://marvelapp.com))
- More time-intensive but provides realistic simulation

**Wizard of Oz Prototypes**

- Human operator manipulates the system behind the scenes
- Allows testing of complex interface concepts before implementation
- Example: A person simulating an automated phone system
- Implements easier parts first while saving complicated parts for later

**Video Prototypes**

- Goal is to persuade potential investors
- Shows what the design will be like in action
- Can incorporate paper prototypes, digital mock-ups, or code
- Benefits:
  - Cheap and fast to produce
  - Effective communication tool
  - Connects interface design to actual tasks
  - Can be created with just a smartphone camera

### Benefits of Prototyping

- Enables rapid design development
- Provides faster feedback before heading down wrong paths
- Makes learning and modification easier
- Allows testing without implementing complicated components
- Serves as an effective tool for pitching ideas

Overview

This session covered paper prototyping techniques for UI/UX design, demonstrating how to create, test, and iterate on low-fidelity prototypes. The presenter showed materials, construction methods, and facilitated a live testing session of a tablet-based app called "Meal Assist" with Dan Whiston.

### Materials and Construction Techniques

- Cardboard backing for durability and a realistic feel
- Printed device templates (tablet outline in this case)
- Cardstock for individual screens that can be swapped out
- Re-stickable tape to easily change screens
- Post-it notes for simulating modal windows
- Tracing paper for overlays to show error states
- Highlighters to simulate interactive elements

### UI Element Libraries

- Create pre-printed sheets of common UI elements
- Cut out individual elements with tabs for easier handling
- Organize elements in containers for quick access
- Time-consuming to set up initially, but saves time when assembling screens
- Makes it simple to add, remove, or reposition interface components

### Simulating Interactivity

- Use foldable elements to simulate accordions or expandable sections
- Apply tracing paper overlays to show state changes without creating new screens
- Swap screens to demonstrate navigation
- Use Post-it notes to simulate modal windows
- Add highlighter colors to show focus states or selection

### Testing and Evaluation Process

- Requires at least two people: a facilitator and a tester
- Set clear goals and expectations for testers
- Document feedback on index cards during testing
- Categorize observations based on type (interactions, etc.)
- Review and prioritize feedback with the team after testing
- Some changes can be made immediately during testing

### Benefits of Paper Prototyping

- Quick to assemble with prepared elements
- Easy to modify on the fly
- Stimulates imagination and creativity
- Creates a tangible experience for testers
- Facilitates immediate feedback and iteration
- Low-cost method to test concepts before development
